# CompraVenta — app para iPhone

App web instalable para encontrar gangas en Wallapop, calcular el beneficio de revenderlas y llevar las cuentas de tus compras y ventas. Funciona dentro del propio iPhone: los datos se guardan en el teléfono y no se envían a ningún servidor propio.

## Instalar en el iPhone

1. Abre la dirección de la app en **Safari** (no en Chrome).
2. Pulsa **Compartir** (cuadrado con flecha) → **Añadir a pantalla de inicio**.
3. Abre CompraVenta desde su icono.

## Uso

- **Inicio → Buscar ofertas ahora.** Tarda unos 2 minutos: deja la app abierta y la pantalla encendida.
- **Oportunidades:** fotos, desglose del beneficio, mensaje para el vendedor y revisión ✅ / ❌.
- **Calculadora**, **Precios**, **Mis operaciones** y **Ajustes** (tu zona, márgenes y modelos).
- **Ajustes → Guardar copia de seguridad** de vez en cuando: si borras la app, los datos se pierden.
